# 🏢 Employee Leave Management — ServiceNow

A **ServiceNow application** for managing employee leave requests, approvals, leave balances, and notifications.

## ✨ Features

* 📝 Employee leave requests
* ✅ Manager approval and rejection
* 📊 Leave balance management
* 🔐 Role-based access control
* 🔄 Automated workflows
* 📧 Email notifications
* 📅 Leave date validation

## 🛠️ Technologies

* ServiceNow
* App Engine Studio
* Flow Designer
* JavaScript
* Business Rules
* Client Scripts
* ACLs

## 🎯 Purpose

This project demonstrates **ServiceNow application development, workflow automation, business rules, client scripts, and access control** for an employee leave management system.
